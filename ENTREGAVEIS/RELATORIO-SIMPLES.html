3. Resumo dos Desafios e Decisões

Desafio encontradoDecisão / Solução adotada
Conta AWS para o grupo Criação de conta nova para uso do Free Tier (12 meses) e acesso compartilhado entre os integrantes.
Subnet Group do RDS exige 2 zonas de disponibilidade Criada segunda sub-rede privada em us-east-1b para atender ao requisito mínimo do RDS Subnet Group.
Aplicação não conectava ao RDS Security Group do RDS corrigido para referenciar o ID do sg-ec2-togglemaster (não um IP fixo).
Porta da aplicação (5000, não 80) Confirmado no código-fonte que Flask/Gunicorn usa porta 5000. Security Group ajustado para TCP 5000.
Manter Gunicorn ativo após fechar SSH Uso de nohup gunicorn --bind 0.0.0.0:5000 app:app & para manter o processo em background.
Credenciais do banco de dados Gerenciadas exclusivamente via variáveis de ambiente (export DB_HOST=...). Nenhuma credencial no código ou no Git.
