Fase 2 — Entregáveis Obrigatórios & Avaliação (90 pts + 10 pts extras)

🎬

Vídeo de Demonstração até 20 min

  • Docker Compose local rodando (9 contêineres: 5 apps + 4 DBs)
  • Cluster Kubernetes na AWS (EKS) com 5 Pods via kubectl
  • Nginx Ingress respondendo a chamadas curl / Postman
  • Carga no evaluation-service + HPA aumentando réplicas
  • Mensagens na fila SQS + analytics-service escalando + DynamoDB
  • Explicação da arquitetura, 3 data stores e desafios da LabRole
☸️

Infraestrutura & Orquestração

  • Dockerfiles multi-stage otimizados + docker-compose.yml
  • 5 Repositórios ECR + 3 RDS Postgres + Redis + DynamoDB + SQS
  • Metrics Server + Nginx Ingress Controller (Load Balancer)
  • Deployments (requests/limits, probes), Secrets (base64) e Services
  • HPA por CPU (Opção A: Academy) ou KEDA por fila SQS (Opção B: Pessoal)

Relatório de Entrega .PDF ou .txt

  • Links dos repositórios GitHub com código e manifestos

  • Justificativas de escalabilidade e comparação dos data stores
